# Мои напоминания

Приложение-напоминалка для Windows 11.

## Возможности
- Создание и удаление напоминаний.
- Изменение статусов.
- Фильтрация по статусу.
- Автоматическое определение просроченных задач.
- Всплывающие уведомления.
- Сохранение данных в SQLite3.

## Технологии
- Python 3.12
- Tkinter
- SQLite3

## Запуск приложения

python main.py
